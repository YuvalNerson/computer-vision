# Computer Vision Coursework

A portfolio of two computer vision assignments completed as part of university coursework. The work covers image classification, feature engineering, deep neural networks, and image captioning.

## Projects

| Assignment | Focus | Start here |
|---|---|---|
| [Assignment 1 — Image Classification](./assignment-1-computer-vision/README.md) | k-Nearest Neighbors, softmax classifiers, HOG features, and fully connected neural networks | [Assignment 1 README](./assignment-1-computer-vision/README.md) |
| [Assignment 2 — CNNs and Image Captioning](./assignment-2-computer-vision/README.md) | Convolutional networks, batch normalization, dropout, and RNN/LSTM-based image captioning in PyTorch | [Assignment 2 README](./assignment-2-computer-vision/README.md) |

## What the work covers

- Implementing and training image classifiers, from distance-based and linear models to fully connected networks.
- Building image features, including Histogram of Oriented Gradients (HOG), and comparing them with learned representations.
- Working through CNN components such as convolution, pooling, batch normalization, and dropout.
- Implementing recurrent sequence components and an image-captioning model with PyTorch.

## Repository layout

- `assignment-1-computer-vision/` — Assignment 1 notebooks, implementation package, and submission material.
- `assignment-2-computer-vision/` — Assignment 2 notebooks and PyTorch implementation.

## Notes

This is a coursework repository. It contains assignment scaffolding and notebooks alongside the implementation work; the assignment READMEs describe the contents of each part. Dataset files are not bundled, so running the notebooks may require downloading the relevant course datasets first.
